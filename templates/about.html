About CardioFusion AI

Quality-aware ECG and clinical data fusion for cardiovascular diagnostic classification.

PROJECT OVERVIEW

Intelligent ECG Analysis Through Multimodal Machine Learning

CardioFusion AI combines 12-lead ECG signals with available patient metadata to support automated classification of cardiovascular diagnostic categories. The platform uses signal feature extraction, separate ECG and clinical models, and quality-aware fusion to produce diagnostic scores.

♡

ECG Signal Analysis

Processes ECG waveforms and extracts statistical signal characteristics.

▤

Clinical Information

Incorporates available age, sex, height and weight information.

◈

Quality-Aware Fusion

Combines branch predictions using signal quality and metadata completeness.

▥

Model Evaluation

Reports macro F1 and AUROC using held-out PTB-XL recordings.

DATA SOURCE

PTB-XL ECG Dataset

The platform uses PTB-XL, a publicly available collection of 12-lead clinical ECG recordings. The current implementation uses 100 Hz ECG waveforms and available metadata.

View official PTB-XL dataset →
